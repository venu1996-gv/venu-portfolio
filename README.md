# Venu Gopal Gattineni — Premium Streamlit AI/ML Portfolio

A recruiter-facing single-page portfolio built in Python with Streamlit.

## Features
- Premium dark AI/ML design
- Top navigation instead of Streamlit sidebar
- Senior AI/ML Engineer hero section
- Recruiter-friendly impact metrics
- Project cards with architecture summaries
- Skills, experience, education, certifications, and contact CTA
- Responsive layout

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Community Cloud
1. Push `app.py`, `requirements.txt`, and `.streamlit/config.toml` to your GitHub repository.
2. Create a Streamlit Community Cloud app.
3. Use `app.py` as the main file.
